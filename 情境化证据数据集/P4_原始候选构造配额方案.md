# P4 原始候选构造配额方案

## 1. 目标与约束

### 总目标

- **原始候选总量**: 4,000 条
- **最终目标**: 经过维度级阈值过滤 + 样本级聚合过滤后,沉淀约 **3,000 条** 高质量数据

### 已确定的过滤策略

- **维度级异常定义**:
  - 若 `|T_d(x) - S_d(x)| > τ_d` **或** `cos(T_d.reason, S_d.reason) < τ_text`
  - 则该样本在维度 `d` 上被标记为异常,记为 `flag_d(x)=1`
- **样本级删除规则**:
  - 仅当 `flag` 的维度数 **≥ 3** 时,删除整条样本

### 经验保留率

基于 480 条黄金基准上的模拟统计:

- **样本级保留率** ≈ **71.7%**
- **样本级删除率** ≈ **28.3%**

因此:


4000 \times 0.717 \approx 2868


再加上 480 条黄金基准:


2868 + 480 \approx 3348


即使考虑后续人工 spot-check、去重和保守删除,最终沉淀 **3,000 条** 是稳妥的。

## 2. 总体配额结构

### 推荐总配额


| 子集       | 原始候选数     | 比例    |
| -------- | --------- | ----- |
| 动态人机交互数据 | **2,800** | 70.0% |
| 静态工程报告数据 | **1,200** | 30.0% |
| **合计**   | **4,000** | 100%  |


### 设计理由

1. 与黄金基准的真实结构基本一致:
  - 黄金基准 = 330 动态 + 150 静态 ≈ **2.2:1**
2. 原始候选进一步强调动态数据的重要性,但不过度挤压静态数据:
  - 候选池 = 2800:1200 ≈ **2.33:1**
3. 这样既能突出论文的核心创新点(动态人机交互评价),又能保留足够强的静态对照与统一框架说服力。

2800 / (10 \times 4) = 70

## 4. 静态数据配额(1,200 条)

1. **章节功能类型(8 类标签)** 做硬配额
2. **学生水平梯度** 做次级配额

## 5. 过滤后保留量预估

### 5.1 总体保留量

若 4,000 条原始候选按“维度级 keep75 + 样本级 ≥3 删除”过滤:


| 阶段          | 数量        |
| ----------- | --------- |
| 原始候选        | 4,000     |
| 预计保留(71.7%) | 2,868     |
| 加黄金基准       | +480      |
| **最终总量**    | **3,348** |


### 5.2 安全余量

这意味着你还可以再承受:


3348 - 3000 = 348


约 **348 条** 的后续人工去重 / 质量复核删除空间。

### 5.3 如果希望更稳妥

若担心实际大规模蒸馏时样本级 reject 会高于黄金基准模拟值,可把原始候选从 4,000 提到 **4,200** 条:


4200 \times 0.717 \approx 3011


再加黄金基准:


3011 + 480 \approx 3491


这会给你额外多约 143 条的缓冲空间。

> **建议**:
>
> - 若 API 预算紧,按 **4,000** 做
> - 若预算允许且希望更稳,按 **4,200** 做

## 6. 执行建议

### 6.1 动态数据

- 严格按 10 领域 × 4 生命周期 × 3 水平配额生成
- 每个小单元格固定 70 条,最容易管理和检查

### 6.2 静态数据

- 以章节功能类型为硬约束
- 以来源类型(立项/结项)为软约束
- 不强行往“4 生命周期”里套

### 6.3 过滤规则

- 先逐维判断 `flag_d(x)`
- 再按样本聚合: **仅当异常维度数 ≥ 3 时删除整条样本**
- 不建议回到“≥2 就删”,会让样本级 reject 上升到 ~56.7%

---

## 7. 最终建议(一页结论)

### 推荐主方案

- **原始候选总量**: 4,000
- **动态**: 2,800
- **静态**: 1,200
- **样本级删除规则**: 异常维度数 ≥ 3 才删

### 若希望更稳

- **原始候选总量**: 4,200
- 动静比例保持不变(约 2.33:1)

### 目标结果

- 最终沉淀 **3,000 条左右** 可用于微调的高质量数据
- 同时保留双源统一(动态 + 静态)叙事的论文说服力
